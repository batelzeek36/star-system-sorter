# Dependency Rules Quick Reference

## ✅ DO

```typescript
// ✅ Import from module index.ts
import { computeScore } from '@/scorer';
import { Button } from '@/components';

// ✅ Screens can import Components
// src/screens/Home.tsx
import { Card } from '@/components';

// ✅ Components can import Utils
// src/components/Card.tsx
import { formatDate } from '@/lib';

// ✅ Internal imports within same module
// src/scorer/score.ts
import { Canon } from './types';
```

## ❌ DON'T

```typescript
// ❌ No deep imports
import { computeScore } from '@/scorer/score';

// ❌ No circular dependencies
// A.tsx imports B.tsx, B.tsx imports A.tsx

// ❌ Utils cannot import Components
// src/lib/helper.ts
import { Button } from '@/components';

// ❌ Components cannot import Screens
// src/components/Card.tsx
import { HomeScreen } from '@/screens';
```

## Layering

```
Screens (top)
  ↓
Components
  ↓
Theme/Tokens
  ↓
Utils (lib, state)
```
