## hdkit

This project uses [hdkit](https://github.com/jonahdempcy/hdkit) by Jonah Dempcy for Human Design chart calculations. hdkit is used under the MIT License.

**Usage:** hdkit provides the core Human Design calculation engine that computes personality types, authorities, profiles, centers, channels, and gates from birth data (date, time, and location). The library is integrated via the `src/hd/hdkit-adapter.ts` module, which wraps hdkit's API and provides a typed interface for the Star System Sorter classification system.
