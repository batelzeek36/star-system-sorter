## Key Findings

### Canon Format Update

Updated canon channel format from `channel_34_57` to `channel_3457` to match the format generated by `score.ts`. This ensures channels in HDExtract (stored as numbers like `3457`) correctly match canon weights.

**Before:**
```typescript
channel_34_57: 20  // Didn't match generated key "channel_3457"
```

**After:**
```typescript
channel_3457: 20   // Matches generated key "channel_3457"
```

### Floating Point Precision

Adjusted percentage sum tolerance from ±0.1% to ±0.2% to account for JavaScript floating point arithmetic precision issues.
